# 🎓 StudyBuddy AI

An AI-powered study assistant that helps students turn notes, PDFs, and course materials into summaries, quizzes, flashcards, and personalized study plans using open-source AI.

## 🚀 Features

- 📄 Note Summarization
- ❓ Quiz Generation
- 🗂 Flashcard Creation
- 📅 Personalized Study Plans
- 🔒 Local AI with Ollama
- 🎓 Student-Friendly Interface

## 🛠 Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3
- SQLite
- GitHub
